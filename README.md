# رفيقي — Web / PWA

تطبيق عربي RTL للقرآن والذكر والصلاة، بدون حسابات أو إعلانات أو تتبع. يحفظ بيانات المستخدم داخل المتصفح، ويضم زرًا مباشرًا لتنزيل تطبيق Android.

## الوظائف

- القرآن كاملًا محليًا: 114 سورة و6236 آية، مع البحث وموضع القراءة والمفضلة والملاحظات.
- اختيار القارئ والتفسير من الإصدارات العربية المتاحة عبر AlQuran.Cloud، مع تثبيت المنشاوي مرتلًا ومجوّدًا وقوائم احتياطية عند انقطاع الاتصال.
- مشغل تلاوة مصغر يمكن إغلاقه ولا يحجب بقية الشاشات، مع خيار متابعة الآيات والسور تلقائيًا.
- الأذكار والرقية والسبحة مع إضافة أذكار مخصصة، والختمة والورد اليومي.
- مواقيت صلاة محسوبة محليًا، اختيار مدينة أو GPS، واتجاه القبلة.
- وضع فاتح/ليلي، تغيير حجم النص، وتعديل التاريخ الهجري.
- Backup/Restore محلي بصيغة JSON.
- PWA قابلة للتثبيت وService Worker للقرآن والمحتوى المحلي.
- تنزيل `Rafiqi.apk` من داخل الواجهة.

## التشغيل والبناء

المتطلبات: Node.js 22.13 أو أحدث.

```bash
npm ci
npm run fetch:assets # عند تنزيل السورس بدون الأصول الكبيرة
npm run dev
```

إنشاء نسخة الإنتاج وتشغيل الاختبارات:

```bash
npm run lint
npm run build
node --test tests/*.test.mjs
```

ناتج الإنتاج يوجد داخل `dist/` ويعمل بواسطة Vinext/Cloudflare Workers.

## النشر على GitHub Pages

المشروع مجهز بملف Workflow داخل `.github/workflows/deploy-pages.yml`. عند الدفع إلى فرع `main` يجلب الأصول الكبيرة الموثوقة من نسخة رفيقي المنشورة، ثم ينشئ نسخة Static وينشرها تلقائيًا. ملف `CNAME` مضبوط على `rafiqi.iegy.net`؛ يلزم توجيه DNS إلى GitHub Pages من لوحة النطاق.

## البيانات والخصوصية

القرآن والأذكار والرقية والمدن مدمجة داخل التطبيق. التلاوة والتفاسير والترجمة تحتاج اتصالًا بالإنترنت وتُجلب مباشرة من AlQuran.Cloud. لا يوجد Backend خاص برفيقي، ولا تُرفع الملاحظات أو المفضلة أو التقدم إلى خادم.

## قيد الأذان في الويب

قد تمنع المتصفحات تشغيل الصوت تلقائيًا في الخلفية أو بعد إغلاق الصفحة؛ نسخة Android هي المرجع لتجربة الأذان والتنبيهات الدقيقة.
